# Remind Me — releases

Downloads and update information for **Remind Me**, a calendar for appointments,
tasks and birthdays with reminders, by BrainsTrust.

- **Download:** see [Releases](../../releases). Windows: the `setup.exe` (recommended) or
  `.msi`; a portable `.zip` that runs without installing; Android: the `.apk`.
- **Problems or suggestions:** open an [issue](../../issues). The app's **Help → Report a
  problem** prepares one for you.

The app's source code is not published. This repository holds only release files and the
signed update manifests the app checks (`stable.json` and `beta.json` in the
`update-manifests` release).
